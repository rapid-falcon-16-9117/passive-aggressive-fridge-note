A tiny Python program that writes one passive-aggressive note from a smart fridge — fourteen door openings last night, only the ice cream taken, and a yogurt from March that has outlived two diets — to `/output/entry.txt`. Nothing else. The note is the whole entry.

## Run it

```sh
python3 main.py
```
